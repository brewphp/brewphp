# Security Policy

## Supported versions

BrewPHP is in early development. Security fixes go to the latest release.

| Version | Supported |
|---------|-----------|
| 0.1.x (in development) | Yes |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately instead:

- through GitHub: **Security → Report a vulnerability** on this repository, or
- by email to **security@brewphp.dev**.

Include the BrewPHP and PHP versions, a description of the problem, and the
steps or a small proof of concept to reproduce it.

We aim to acknowledge reports within 3 working days and to ship a fix or a
mitigation within 30 days. We will credit you in the release notes unless
you prefer otherwise.
